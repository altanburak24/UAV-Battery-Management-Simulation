# UAV-Battery-Management-Simulation
C++ Pointer mantığı ile İHA batarya geçiş simülasyonu.
Bu proje,bir İHA'nın yedekli batarya sistemleri arasındaki geçiş mantığını simüle etmek için geliştirilmiştir.C++ Pointer yapısını kullanarak bellek yönetimi ve dinamik veri erişimi üzerine pratik yapmayı hedefler.
